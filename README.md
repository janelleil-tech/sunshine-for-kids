# Sunshine for Kids

Starter website for the Sunshine for Kids digital activity project.

## Files
- `index.html` — homepage
- `category-*.html` — category pages
- `activities/draw-your-mood.html` — first drawing activity
- `style.css` — website styling
- `drawing.js` — private, in-browser drawing canvas
- `images/sunshine-logo.png` — uploaded Sunshine for Kids logo

## Adding a Canva activity later
Export the finished Canva page as a PNG, put it in `images/`, then the activity template can use that PNG as the worksheet underneath the drawing canvas.
